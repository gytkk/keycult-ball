# 프로젝트 맥락과 설계 결정

작성일: 2026-10-29. 현재 저장소가 후속 작업의 기준 위치다. 대화 원문을 옮긴 문서가 아니라, 설계에 필요한 요구사항·근거·남은 질문만 정리했다.

현재 보유 제품은 사용자 확인 기준 NovelKeys 최신 판매 버전의 No.1/60 WK이며 WT60-A와 호환된다. 정확한 리비전과 기존 공개 보강판 CAD의 실물 적합성은 아직 확인되지 않았다. 사용자는 외부 트랙볼을 이미 충분히 사용했으며 이번 프로젝트의 목적은 G/H 사이 중앙 통합이다. 외부 별도 장치는 후보에서 제외한다. 34mm Keyball은 현재 생성된 예비 배치의 기준이며 고정 요구사항은 아니므로 작은 볼과 터치패드도 중앙 통합 후보로 검토한다. [실현 가능성과 대안 조사](feasibility.md)는 후보 비교이며 최종 장치와 새 배열은 아직 선택하지 않았다.

## 1. 요구사항과 작업 경계

| 항목 | 현재 요구사항 / 경계 |
|---|---|
| 보존 대상 | Keycult No.1/60 케이스. 새 케이스 구멍·절삭 없이 장착하는 것이 목표 |
| 교체 대상 | 중앙 통합을 위한 PCB와 플레이트 교체 |
| 배열 | 1u=19.05mm 직교 배열, 5행을 우선 검토. 문자 순서는 QWERTY |
| 포인팅 | G/H 사이 중앙 통합 필수. 현재 예비 배치는 34mm Keyball 기준이며 작은 볼과 터치패드도 검토 가능. 트랙볼을 사용하면 볼과 센서의 상대 광학 위치 유지 |
| 연결·펌웨어 | 유선 USB, QMK 기반 키보드+포인팅 장치. 외부 별도 장치와 무선은 현재 범위 밖 |
| 현재 산출물 | 출처 있는 예비 배치, 키 중심 좌표, 평면/단면 그림, 수치 검증, 종이 검증 자료 |
| 아직 하지 않은 일 | 회로/PCB 설계, 가공용 플레이트, 펌웨어 포팅, 구매·제조·케이스 가공 |

## 2. 결정과 이유

1. **15u·중앙 3u·66키를 추천 기준안으로 유지하고 63키 옵션을 별도로 비교**한다. 기준안은 좌우 6열씩과 중앙 3열을 배치하고 가운데 3×3칸을 비워 50mm 임시 조립 영역과 수·문자·수정키를 유지한다. `layout.json`의 `rear_clearance`는 상단 중앙 Vol-/Mute/Vol+만 제거해 중앙 빈 명목 영역을 3열 × 4행, 57.15 × 76.20mm로 늘린다. 볼 지름 34mm와 중심 `(0, 0)`, G/H x=±38.10mm, 하단 M1/M3/M2와 나머지 키는 그대로다. 추가한 뒤쪽 19.05mm는 센서·배선, 재료를 남긴 지지 브리지와 넓은 체결 간격을 검토하기 위한 공간이다. 키 제거 자체는 강성 향상을 보증하지 않으며 전체 직사각형 절개는 오히려 강성을 낮출 수 있다. 50×50mm 임시 예약 영역과 미확정 수직 공간은 바꾸지 않는다.
2. **14u·중앙 2u·64키는 비교만 하고 보류**한다. Ø34 볼 자체는 들어가지만, 홀더/센서/나사까지 포함한 수납 근거가 없다. 50mm 예약 영역은 키캡과 5.425mm 겹친다. 실물의 높이별 외곽이 더 작으면 재검토할 수 있다.
3. **현재 생성된 예비 배치는 Keyball을 기준으로 유지**한다. 최초 검토 대상인 34mm 시스템이며 공개 조립 가이드·센서 자료를 활용할 수 있다. 공개된 센서 기판 외곽과 실제 홀더 외피는 다른 정보다. 원형 Ploopy Nano/Mini는 38.10mm, Classic은 44.45mm여서 34mm 드롭인 대체품이 아니다. Charybdis는 같은 34mm지만 별도 장착 설계가 필요하다. 제품별 센서·지지 구조·라이선스는 [별도 비교](alternatives-and-licenses.md)에 기록한다. 중앙 통합이 가능한 소형 장치는 [대안 조사](feasibility.md)에서 비교하며, 기존 산출물 유지가 최종 장치 선택을 뜻하지 않는다.
4. **볼+센서는 같은 강체에 고정**한다. 우선 새 플레이트에 하나의 모듈로 장착하고 중앙 보강을 검토한다. 공간·강성 결과에 따라 기존 케이스 체결점을 쓰는 가역 브래킷도 검토한다. 볼은 케이스, 센서는 휘는 플레이트에 따로 고정하지 않는다.
5. **GH60 공개 KiCad 도면을 출발점으로 새 PCB를 설계한다.** 보강판이 케이스에 결합하고 PCB는 스위치를 통해 지지되므로, WT60-A와의 작은 외곽 치수 차이만으로 GH60 기반 설계를 배제하지 않는다. Poker2 규격 WT60-D가 USB-C 제거와 JST 커넥터 추가 후 No.1/60에 장착된다는 제품 설명을 근거로 삼는다. WT60-A의 정확한 PCB CAD 확보를 설계 시작의 선행 조건으로 두지 않는다. 사용할 GH60 파일과 호환 근거, 도터보드 연결 조건은 [PCB 설계 출발점](../design/preliminary/design.md#pcb-설계-출발점)에 기록한다. 최종 외곽과 중앙 개구, 부품 배치 및 제조 데이터는 FreeCAD에서 공식 STEP와 실측 모듈의 기구 스택을 대조한 뒤 확정하며, 예비 SVG를 제조 DXF로 바꿔 바로 발주하지 않는다.

## 4. 검증된 범위와 그 한계

- 모든 키 중심, 키 수, 피치, 키캡/스위치 비교 사각형의 쌍별 충돌, 볼–키 거리, 50mm 예약 영역–키 간격을 계산했다.
- 66키안은 볼–키캡 **12.10mm**, 예약 영역–키캡 **4.10mm**, 인접 키캡 **1.05mm**의 최소 평면 간격이다.
- 63키 옵션도 공개 평면 검사와 별도 1:1 A3 인쇄 자료로 비교한다. 과거 공식 윤곽 검사 기록은 이 새 옵션을 검증한 결과가 아니며, 장착 안정성과 실제 수납은 미확정이다.
- **현재 공개 검증**은 285.75×108.25mm 일반 직사각형 치수 경계 내 포함과 부품 간 평면 간격을 다룬다. 이 직사각형은 공식 플레이트 형상이 아니므로 탭·둥근 모서리에서의 실제 포함 관계를 증명하지 않는다.
- **과거 공식 윤곽 관측**은 [plate-containment.json](../design/preliminary/plate-containment.json)에 수치 기록으로 남겼다. 당시 66키안의 스위치 비교 사각형과 키캡은 모두 공식 DXF 윤곽 안에 있었고, 키캡–윤곽 최소는 모서리에서 **약 0.327mm**였다. 현재 공개 검증이 이 결과를 다시 계산하는 것은 아니다. 공식 DXF를 로컬 취득한 뒤 `uv run scripts/verify_official_contour.py`로 별도 재현하며, 정확한 좌표·재검사 출력은 Git에서 제외하는 `design/preliminary/sources/local/`에 저장한다.
- **직사각형 경계 포함 ≠ 정확한 플레이트 윤곽 포함 ≠ 케이스 개구부 통과 ≠ 조립 가능 ≠ 제조 검증 완료**다.
- 인쇄 PDF의 100mm 기준선은 내부 벡터로 검증했다. 프린터에서는 100% 실제 크기 출력 후 자로 재확인한다.

## 5. 다음 단계: 실측 기록표

실측 전에는 빈칸을 추정값으로 채우지 않는다. 좌표는 플레이트 기준점과 방향을 함께 기록한다.

| 필요 항목 | 값 / 기록 | 결정에 미치는 영향 |
|---|---|---|
| 케이스 정확한 리비전 및 현재 PCB/플레이트 모델 | NovelKeys 최신 판매 버전, WK 및 WT60-A 호환은 사용자 확인. 정확한 리비전과 PCB/플레이트 모델은 미확정 | 정렬·탭·도터보드 호환 |
| 내부 개구부 W/H, 네 코너 반경, 턱, 중심 오프셋 | 미측정 | 15u/14u, 끝 키·키캡 통과 |
| 중앙 및 주변 플레이트 윗면→바닥/리브/나사/무게추 거리 | 미측정 | 볼 하단·홀더·PCB·배선 수납 |
| 실제 키캡 하단·최대 스트로크 외곽 | 미측정 | 현재 18mm 가정의 유효성 |
| Keyball 홀더 정확한 리비전, 최대 XY, 체결부·플랜지 | 미측정 | 중앙 3u 영역과 개구 설계 |
| 볼 중심 Z, 홀더 전체 높이, 센서/렌즈/커넥터 돌출 | 미측정 | 높이별 충돌, 광학 위치 |
| 모듈 장착 홀 좌표와 조립/분해 경로 | 미측정 | 플레이트/브래킷 설계 |
| 도터보드 모델·장착 홀·커넥터·핀순서·케이블 굴곡 | 미확정 | USB 배선·보호회로·PCB 인터페이스 |
| 플레이트 최대 하향 휨과 볼 조작 시 상대 변위 | 시제품 필요 | 바닥 여유·보강·센서 안정성 |

### 순서

1. 위 치수와 리비전을 확보한다.
2. 66키 기준안과 63키 옵션의 A3 1:1 종이 배치를 실제 플레이트에 맞춰 G/H 간격·손가락 접근을 확인한다. 뒤쪽 확보 공간은 센서·배선 및 지지체의 실제 외곽과 대조한다.
3. 실제 홀더의 STEP 또는 실측 모형으로 FreeCAD 합본 간섭 검사를 한다. 동일 강체의 센서·볼 광학 간격을 보존한다.
4. 플레이트 마운트 / 기존 체결점 브래킷 중 가능한 구조를 선택하고 휨·조립 경로를 확인한다.
5. USB 도터보드와 MCU/센서 전압·로직을 확정한다. 실제 핫스왑 소켓 채택 여부도 수직 여유를 보고 결정한다.
6. GH60 도면을 바탕으로 시작한 KiCad 회로/PCB의 외곽과 부품 배치를 확정하고, 실제 개구·체결 도면, QMK 포팅 및 제조 검토를 진행한다.

## 6. 자료 관리

이 저장소에 들어 있는 것은 검토 가능한 설계 맥락과 독립 레이아웃 산출물이다. 원본 대화·개인 메모·실행 환경 인증 정보는 옮기지 않았다. 원본 CAD/센서 파일은 출처·해시와 로컬 다운로드 스크립트로 참조한다. 공개 SVG/HTML/PNG/PDF에는 공식 윤곽 대신 일반 직사각형 치수 경계만 넣는다. 정확한 윤곽 좌표 `design/preliminary/sources/local/measured-official-dxf.json`과 재검사 출력은 Git에서 제외한다. 형상을 복제하지 않는 STEP 바운딩 치수 요약과 과거 윤곽 검사의 수치 기록은 공개한다. 로컬 원본 사용도 Keycult 조건을 따르며, [라이선스 비교](alternatives-and-licenses.md)를 확인한다.
